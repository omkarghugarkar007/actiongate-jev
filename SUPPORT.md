# Support

For setup help, integration questions, policy design, and examples, use [GitHub Discussions](https://github.com/omkarghugarkar007/actiongate-jev/discussions).

For reproducible defects, open a bug report with sanitized inputs and environment details. For feature ideas, explain the agent workflow, affected risk class, failure behavior, and how the feature should be evaluated.

Do not post API keys, authorization headers, tool credentials, customer data, or vulnerability details publicly. Security reports follow [SECURITY.md](SECURITY.md).
